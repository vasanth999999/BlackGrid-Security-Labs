# BLACKGRID SECURITY LABS — Website Source

## Run locally
1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Use the Live Server extension and open `index.html`, or serve the folder with any static HTTP server.
4. No build step or frontend framework is required.

## Main pages
- `index.html` — Home, rotating hero, technology services, popular course slider, blogs and trusted partner.
- `services.html` — Dedicated technology services with alternating image/content sections.
- `courses.html` — BlackGrid Academy catalogue.
- `about.html` — Who We Are, Vision and Mission.
- `contact.html` — Phone, WhatsApp, email, map and enquiry form.
- `workshops.html` — Live Events and workshops.
- `blogs.html` — Articles.
- Remaining category pages — course category details.

## Customization
- `css/style.css` — design tokens, colours, responsive layouts and components.
- `js/script.js` — hero carousel, course slider, navigation and form interactions.
- `assets/images/` — website imagery.
- Main brand palette: #FFFFFF, #003B9A, #0054E5, #00D4FF, #101B35, #F0F5FF.
- Academic & Career Development uses the separate teal palette in the CSS theme.

## Carousel behaviour
- Hero banner rotates automatically every 2 seconds.
- Popular Courses shows 5 cards on desktop, 4 on laptop, 2 on tablet and 1 on mobile.
- Course carousel supports previous/next controls and touch swipe.
